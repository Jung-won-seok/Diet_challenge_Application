# 크로스핏 레벤 존다(Zone Diet) 챌린지 어플

크로스핏 레벤(CrossFit LEBEN)의 존 다이어트(Zone Diet) 챌린지를 위한 모바일 웹앱(PWA)입니다.  
매일 단톡방과 네이버 카페에 식단과 탄단지 블록을 보고하는 번거로움을 줄이고, 조별 실시간 인증 현황 및 패널티를 체계적으로 관리할 수 있도록 제작되었습니다.

---

## 🏋️ 챌린지 개요 및 규칙

- **참가 인원**: 약 20명 (4명씩 5개 조 구성: 1조 ~ 5조)
- **일일 식단 인증**:
  - 매일 밤 12시(자정) 전까지 각 끼니별 사진 및 탄수화물·단백질·지방 블록 기록
  - 조별 단톡방 식단 및 탄단지 비율 보고
  - 네이버 크로스핏 카페에 하루 식단 사진 및 블록 수 게시글 작성
- **주간 미션 운동**: 매주 코치가 지정한 운동 미션 완주 및 인증
- **패널티 및 벌금 규정**:
  - ① 하루 정해진 개인 목표 블록 초과 섭취
  - ② 밤 12시 전 조별 단톡방 식단 미보고
  - ③ 밤 12시 전 네이버 카페 식단글 미작성
  - ④ 주간 미션 운동 미수행
  - **벌금**: 패널티 1회당 **10,000원** (개인당 최대 10회 = 100,000원 한도)

---

## ✨ 핵심 기능

1. **식단 사진 & 탄단지 블록 간편 입력**
   - 끼니별(아침/점심/저녁/간식) 사진 업로드 (모바일 최적화 자동 압축)
   - 1~5블록 원터치 정석 버튼 및 개별 탄·단·지 ±0.5 블록 미세 조절
   - 일일 목표 블록 대비 진행률 바 및 실시간 탄:단:지 비율(40:30:30) 자동 계산
   - 목표 블록 초과 시 실시간 경고 및 밤 12시 마감 카운트다운 타이머

2. **네이버 카페 & 조별 단톡방 원클릭 공유 도우미**
   - **오늘의 식단 요약 카드 이미지(PNG) 자동 생성**: 오늘 먹은 모든 끼니 사진과 탄단지 블록 현황을 한 장의 이미지로 자동 합성하여 다운로드 및 모바일 공유
   - **조별 단톡방 보고 문구 1클릭 복사**: 식단, 탄단지 블록 및 비율 요약 텍스트 복사 + '단톡 보고완료' 자동 체크
   - **네이버 카페 게시글 양식(제목/본문) 1클릭 복사**: 양식 복사 + '카페 작성완료' 자동 체크

3. **5개 조(1~5조) 실시간 현황 보드**
   - 각 조별 4명의 인증 상태(식단 입력, 단톡 보고, 카페 업로드, 주간 미션) 실시간 모니터링
   - **단톡 독촉문구 1클릭 복사**: 밤 12시 전 아직 인증하지 않은 조원 명단을 포함한 알림 멘트 자동 생성

4. **주간 미션 운동 & 패널티/벌금 트래커**
   - 이번 주 미션 운동 확인 및 수행 인증
   - 개인별 10칸 패널티 게이지 바 및 누적 벌금 현황
   - 챌린지 전체 모인 벌금 풀 집계 및 세부 패널티 로그

5. **코치/운영진 관리자 모드 (PIN 보호)**
   - **일일 마감 위반자 자동 스캔**: 밤 12시 기준 블록 초과, 단톡 미보고, 카페 미작성자를 1초 만에 추출하여 일괄 패널티(1만원) 부여
   - 20명 참가자 명단, 조 편성, 목표 블록, 개인 PIN 수정 및 추가/삭제
   - 주간 미션 운동 및 카페 링크 설정
   - 데이터 초기화 및 데모 데이터 복원

## 🚀 실행 방법

### 요구 사항
- [Node.js](https://nodejs.org/) v18 이상 (외부 의존성 패키지 설치 없이 표준 라이브러리로 구동)

### 로컬 실행
```bash
# 서버 실행
node server.js

# 또는 윈도우 환경에서 배치 파일 더블클릭
레벤존다_서버실행.bat
```

- **PC 접속**: `http://localhost:3000`
- **모바일 접속 (동일 Wi-Fi)**: 콘솔에 출력되는 IP 주소 (예: `http://192.168.x.x:3000`)
- **PWA 지원**: 스마트폰 브라우저에서 '홈 화면에 추가'를 누르면 네이티브 앱처럼 실행 가능합니다.

## 📂 프로젝트 구조

```
├── server.js              # Node.js REST API & 정적 파일 웹 서버 (데이터 영속화)

├── 레벤존다_서버실행.bat    # 원클릭 서버 실행 배치 스크립트
├── data/
│   └── store.json         # 참가자, 식단, 미션, 패널티 데이터 저장소
└── public/
    ├── index.html         # 메인 웹앱 마크업 (PWA)
    ├── styles.css         # 모바일 퍼스트 반응형 스타일링
    ├── app.js             # 웹앱 클라이언트 로직
    ├── card-generator.js  # Canvas 기반 식단 요약 카드 이미지 & 공유 텍스트 생성기
    ├── manifest.json      # PWA 매니페스트
    ├── sw.js              # 서비스 워커
    └── icon.svg           # 앱 아이콘
```
